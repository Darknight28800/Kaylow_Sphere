# Polices

Fichiers `woff2` (sous-ensemble latin) issus de [Fontsource](https://fontsource.org),
chargés par `next/font/local` dans `app/layout.tsx`.

| Police | Graisses | Licence |
|---|---|---|
| Inter | 400, 500, 600 | SIL Open Font License 1.1 |
| Poppins | 500, 600, 700 | SIL Open Font License 1.1 |
| JetBrains Mono | 400, 500 | SIL Open Font License 1.1 |

Auto-hébergées pour que le build ne dépende pas de Google Fonts (un échec
réseau pendant `next build` faisait échouer le déploiement Hostinger).
